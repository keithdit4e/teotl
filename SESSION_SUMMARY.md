## User Workflows

### Workflow 1: Setup Agent with Wizard

```bash
$ python3 -m forge.cli.wizard

# Choose "Planner-Worker" pattern
# Select Claude models (Sonnet for planner, Haiku for worker)
# Select skills: Filesystem, Git, Claude_Code
# Configure harness features
# Wizard generates config.yaml + run_planner_worker.py

✅ Agent ready!
```

### Workflow 2: Run Complex Coding Task

```bash
$ echo "Migrate authentication to use JWT tokens" > GOALS.md
$ python3 run_planner_worker.py

# Planner creates 8-step plan ($0.10)
# Review plan
# Approve execution
# Worker executes steps ($0.04)
# Worker uses Claude Code for coding steps ($0.04)
# Total cost: $0.18 (vs $0.80 traditional)

✅ Task complete with 77% cost savings!
```

### Workflow 3: Autonomous Coding Agent

```bash
# 1. Setup hybrid pattern (daemon + planner-worker)
$ python3 -m forge.cli.wizard
# Choose "Hybrid" pattern

# 2. Start daemon for routine tasks
$ python3 -m forge.daemon.run --config config.yaml

# 3. Daemon processes simple tasks autonomously
# 4. For complex tasks, daemon creates plan
# 5. Planner-Worker executes complex task
# 6. Claude Code handles coding steps

✅ Fully autonomous coding agent!
```

## API Key Clarification

**Important:** Since you're already using Claude Code CLI, you already have API access!

### What You Need
1. **Same API key** you use for Claude Code CLI
2. Set environment variable: `export ANTHROPIC_API_KEY="your-key"`
3. Run wizard, it will detect and use your existing key

### Cost
- Your Claude Pro subscription: **NOT used by agents**
- Claude API (same as Claude Code): **Pay per token**
- Haiku model: **~$0.005 per task** (very cheap!)
- Cost with Planner-Worker: **77% less** than traditional
