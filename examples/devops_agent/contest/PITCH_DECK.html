Where It Works

Works Well For

  • Typos and syntax errors
  • Wrong operators (+, -, *, /)
  • Missing return statements
  • Simple null/zero checks
  • Obvious logic fixes
  • Well-described GitHub issues

Limitations

  • Complex architectural bugs
  • Performance issues
  • Security vulnerabilities
  • Bugs requiring deep domain knowledge
  • Multi-file refactoring
  • Vague or incomplete issue descriptions
This is a tool, not a replacement for developers. It handles routine work so developers can focus on harder problems.

How It Works

HEARTBEAT DAEMON (polls every 10s)
▼
Check GitHub for new issues
▼
Create TASK for each issue
▼
AGENT: Clone → Read → Fix → Test → PR
▼
Human reviews and merges PR

Safety Features

  • No direct commits to main — all changes via PR
  • Command allowlist — only safe operations permitted
  • Timeout limits — prevents runaway execution
  • Human approval required — agent never merges its own PRs

Vision: Specialized Agent Teams

Why One Agent Has Limitations
